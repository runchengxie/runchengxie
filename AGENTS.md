# Profile README editing guide

This repository contains the GitHub profile README for `runchengxie`. Changes should keep the page useful to a first-time visitor and should reflect the current public project portfolio.

## Before editing

1. Inspect the complete list of public repositories on GitHub.
2. Check each relevant repository's latest update, README, description, and current status.
3. Look for newly created projects, meaningful recent changes, renamed repositories, archived work, and projects that have become central to the current workflow.
4. Check every repository link in the profile README.
5. Rank featured projects by current importance, technical substance, activity, and how clearly they represent the author's present work. Record the reasoning in the change description when the order changes.

The profile README is a curated introduction. It does not need to list every repository. Include a project when it is active, representative, useful to visitors, or especially distinctive. Leave out small utilities, historical compatibility repositories, and inactive experiments unless they add important context.

## Project descriptions

- State what the project does and who it is for.
- Prefer concrete capabilities over broad claims.
- Keep each description short enough to scan quickly.
- Describe the repository's current role. Mention migrations or superseded projects only when that context helps readers avoid confusion.
- Do not claim that a repository is public, private, active, canonical, or maintained without checking its current state.
- Use repository names and inline code consistently.

## Chinese writing style

中文简介面向中文母语读者，优先使用自然、直接、易懂的表达。

- 排查用语深奥、翻译腔、无必要的中英混杂和重复信息。
- 中文说明优先使用中文标点，例如全角括号和逗号。
- 保留必要的行内代码引用，例如 `quant-platform`。
- 少用双引号、加粗、分号和破折号。
- 少用网文式表达、空泛的总结和模板化点评。
- 能直接陈述的信息直接表达，避免堆叠前置否定和不是……而是……式转折。
- 保持句子简洁，必要时拆分长句。

## Validation

After editing, verify that:

- all featured project links resolve to the intended GitHub repositories
- project names, descriptions, and public or private labels match the repositories checked
- English and Chinese sections describe the same current portfolio
- the Markdown renders cleanly
- the working tree contains only the intended README and instruction changes
